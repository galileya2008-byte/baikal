# Аренда хивуса на Байкале — проект для Cursor и GitHub Pages

Готовый статический сайт: HTML, CSS и JavaScript. Сборка, npm, база данных, сервер и ключи API не требуются.
Контакт бронирования: https://t.me/MariaPM65.

## Начало работы
1. Распакуйте архив.
2. В Cursor выберите File → Open Folder и откройте папку baikal-khivus, где находится index.html.
3. Откройте CURSOR_PROMPT.md, скопируйте текст задания в чат Cursor в режиме Agent.
4. Для быстрого просмотра откройте index.html в браузере. Также можно использовать локальный HTTP-сервер, например `python -m http.server 8000`, если установлен Python.

## Файлы
- index.html — разделы страницы и основная разметка.
- style.css — дизайн и мобильная версия.
- app.js — данные маршрутов, галерея, модальные окна, меню, ссылки Telegram.
- assets/reference.jpg — исходный макет 653 × 1280 px и временный источник фотографий.
- .nojekyll — отключение обработки Jekyll для статического сайта.
- .gitignore — исключение локальных и временных файлов.
- CURSOR_PROMPT.md — задание для Cursor.

## Публикация через GitHub Pages
1. Создайте новый репозиторий GitHub, например baikal-khivus. На бесплатном тарифе используйте публичный репозиторий.
2. Загрузите содержимое папки baikal-khivus в ветку main. Файл index.html должен находиться в корне репозитория, а не внутри дополнительной вложенной папки.
3. Откройте Settings → Pages → Build and deployment.
4. Source: Deploy from a branch. Branch: main. Folder: /(root). Нажмите Save.
5. Дождитесь успешной публикации. Точный адрес покажет GitHub в Pages.
6. Обновления в main автоматически публикуются тем же способом.

Если используете Git из Cursor: сначала проверьте авторизацию GitHub и наличие Git; создайте репозиторий, затем выполните commit и push через интерфейс Source Control. Не вводите токены в исходный код.
Свой домен не настроен: CNAME намеренно отсутствует.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Реализовано
12 блоков по макету; адаптивные стили; навигация по секциям; 7 карточек маршрутов с подробностями; галерея с увеличением фото; мобильное меню; три тарифа; переходы в Telegram. Сообщения только подставляются в ссылку, сайт не отправляет их автоматически. Подстановка текста зависит от клиента Telegram.

## Что проверить перед запуском для клиентов
- Фотографии заменены отдельными WebP-изображениями высокого разрешения. Сейчас это изображения, созданные с помощью ИИ, а не документальные фотографии конкретных поездок или оригинальные материалы владельца.
- Вёрстка передаёт макет, но точное попиксельное совпадение и браузерная визуальная проверка не подтверждены. Шрифты заменены системными; рукописный акцент зависит от установленного шрифта.
- Цены перенесены из макета: час 6 500 ₽, день 40 000 ₽, сутки 80 000 ₽. Подтвердить актуальность у владельца.
- Продолжительность, описания маршрутов и вместимость требуют подтверждения владельцем. Часть мелкого текста макета восстановлена по смыслу.
- Instagram и MAX не подключены: адреса не предоставлены.
- Стрелки маршрутов выбирают и подсвечивают карточки; это не карусель маршрутов. Галерея прокручивается.
- Заявка направляется в чат Марии. Система онлайн-оплаты или подтверждения брони не реализована.

## Как заменить фото после получения оригиналов
Сохранить оптимизированные оригиналы в `assets` с понятными именами. В `index.html` обновить атрибуты `data-image`, а в массивах `routes` и `photos` файла `app.js` — относительные пути. Размеры, скругления и кадрирование через `object-fit: cover` уже настроены. `reference.jpg` используется только как визуальный референс макета и на странице не загружается.
